<div align="center">
  <h1>Manejo De Datos</h1>
</div>
<p>todosLosPokemones = []: Arreglo principal que almacena los 500 pokemones descargados de la API.</p>
<p>pokemonesFiltrados = []: Version filtrada que cambia cada vez que se busca algo.</p>

<div align="center">
  <h1>Metodos De Arreglos</h1>
</div>
<p>map(): Recorre el arreglo de datos devuelto por PokeAPI y crea un nuevo arreglo con los datos de los pokemones y otro con sus tipos.</p>
<p>filter(): Crea un nuevo arreglo con los elementos que cumplen con ciertas condiciones.</p>
<p>includes(): Verifica si un arreglo contiene un elemento y devuelve true o false.</p>
<p>slice(): Extrae un conjunto de elementos del arreglo sin modificar el original.</p>
<p>forEach(): Ejecuta una función por cada uno de los elementos de un arreglo (renderizar HTML e insertar opciones en un <select>).</p>
